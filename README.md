# Python Scripting & Application Showcase

## 📌 Portfolio Overview
This repository contains a curated selection of Python applications developed to demonstrate proficiency in data manipulation (Pandas), API integration, JSON data handling, and Graphical User Interface (GUI) development (Tkinter). 

These scripts serve as foundational building blocks for rapid prototyping, data pipelines, and automation tasks.

## 🗂️ Project Directory

### 1. [Capstone] Language Flash Card Application
**Folder:** `Day 31 - Flash Card App Capstone Project`
*   **Description:** A dynamic flashcard program designed to facilitate language learning through spaced repetition.
*   **Core Concepts:** Data manipulation using **Pandas** to read, filter, and update CSV datasets (`french_words.csv` to `words_to_learn.csv`). 
*   **UI/UX:** Built with Tkinter, featuring dynamic canvas image updates and asynchronous window delays (`window.after`).

### 2. External API & SMS Notification Service
**Folder:** `Day 35 - Keys, Authentication & Environment Variables, Send SMS`
*   **Description:** An automated weather tracking script that queries external API endpoints and triggers SMS notifications if specific atmospheric conditions (e.g., rain) are met.
*   **Core Concepts:** HTTP requests, JSON payload parsing, and secure handling of API keys, authentication tokens, and environment variables. Demonstrates the foundational logic required to integrate third-party services like Twilio.

### 3. Encrypted Password Manager
**Folder:** `Day 29 - Password Manager GUI App with Tkinter` & `Day 30`
*   **Description:** A local desktop application that generates secure passwords and saves credential sets.
*   **Core Concepts:** Error handling (`try/except/finally` blocks) and persistent data storage using nested **JSON** dictionaries. 

### 4. US States Geospatial Guessing Game
**Folder:** `Day 25 US States`
*   **Description:** An interactive map game requiring users to input the names of US States, which are then dynamically plotted on screen via coordinate mapping.
*   **Core Concepts:** Advanced **Pandas** operations, extracting specific row coordinates based on string matching to map user inputs to X/Y geospatial coordinates.
